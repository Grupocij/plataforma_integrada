Avisos no celular

Cole a chave pública de Web Push do projeto plataforma-cij. Somente usuários Master podem alterar esta configuração.

  1. Abra o Firebase → Configurações → Cloud Messaging.
  2. Em Configuração da Web → Certificados de push da Web, clique em Gerar par de chaves, se ainda não existir.
  3. Copie a chave pública e cole abaixo.

Entre no Portal para carregar a configuração.

Depois de salvar, cada técnico deve abrir o app uma vez, entrar em Alertas e tocar em Ativar no dispositivo. Use Testar push para conferir.
